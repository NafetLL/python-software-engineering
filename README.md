# Python Software Engineering Bases

Portfolio of core Python engineering implementations covering Object Oriented Programming (OOP), JSON data persistence, and resilient REST API integrations.

## Mastered Engineering Pillars

* **01. OOP & Data Unpacking:** Dynamic keyword arguments (`**kwargs`), dictionary mutation, and in-memory references.
* **02. JSON Persistence & Algorithms:** Structured list-of-dictionary records, `lambda` sorting algorithms, and disk persistence using `json.dump()`.
* **03. Resilient Web APIs:** HTTP GET requests using `requests`, `params` dictionaries, `timeout` guards, and `try/except` network error prevention with `response.raise_for_status()`.

## Repository Structure

* `01_oop_fundamentals/`: OOP class designs and financial conversion logic.
* `02_json_persistence/`: Task management, inventory tracking, and scholarship evaluators saving to `.json`.
* `03_web_apis/`: Production-grade GitHub Tech Radar with network failure shielding.
